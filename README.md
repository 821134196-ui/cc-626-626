# 公共停车场新能源车位占用举证系统

巡查员发现新能源专用车位被占用后提交证据（车位号、车牌、发生时间、现场照片），
值班员核实后短信通知车主，**复查确认车辆离开后才能结案** —— 短信发送成功不能代替复查。

## 一条命令启动

```bash
./start.sh
```

启动后访问 http://localhost:3000 （前端构建产物由后端直接托管）。

## 业务流程

```
巡查员举证(车位+车牌+时间+照片)
   │  同一车位有未结案事件 → 自动归并为该事件的新举报（不重复立案）
   ▼
待核实 ──值班员核实（人工确认车牌，识别结果仅辅助）──▶ 待通知
   │                                                    │
   └──值班员驳回──▶ 已驳回                        值班员发短信(模拟)
                                                        ▼
                                              已通知 · 待复查 ◀──┐
                                                        │        │ 复查仍占用/再次通知
                                  巡查员复查"已离开" ────┘        │
                                                        │        │
                                                        ▼        │
                                              值班员结案 ──▶ 已结案
                                            （须最后通知之后有"已离开"复查）
```

关键规则：

- **重复举报归并**：同一车位存在未结案事件时，新举报挂到该事件下；车辆离开结案后再次占用才新建事件。
- **短信 ≠ 驶离**：结案要求"最后一次通知之后存在复查=已离开"的记录；未复查/复查仍占用/再次通知后旧复查失效，均不能结案。
- **车牌识别仅辅助**：照片不清晰时标记"转人工核实"；核实必须由值班员人工确认车牌，通知只发给人工确认的车牌，绝不直接采用识别结果。
- **岗位权限**：服务端按会话角色校验（巡查员：举证/复查；值班员：核实/通知/结案），请求体中伪造角色无效；事件资料按角色与参与度控制可见性。

## 技术栈与结构

- 后端：Rust + Axum + SQLx + SQLite（`src/`），照片存本地 `uploads/`，数据库 `data/parking.db`
- 前端：Svelte + Vite（`frontend/`），移动端优先，巡查员首页优先展示待复查车位
- 车牌识别 / 车主通讯录 / 短信网关均为模拟实现（`src/mocks.rs`）：
  - 照片 < 2KB 或文件名含 `blur` 视为"看不清"，触发人工核实
  - 手机号由车牌确定性生成；短信打印到服务端日志并标记 `sent`

## 验证

```bash
cargo test        # 5 个端到端集成测试
```

覆盖：① 重复举报归并；② 岗位权限与篡改请求越权结案被拒；③ 结案后再次占用重新立案；
④ 通知发出但车辆未离开仍待处理（未复查/复查仍占用/再次通知后均不能结案）；
⑤ 照片不清晰转人工核实、通知只发人工确认车牌。

## 主要 API

| 方法 | 路径 | 岗位 | 说明 |
| --- | --- | --- | --- |
| POST | /api/login | - | 登录，返回 token |
| POST | /api/reports | 巡查员 | multipart 举证（spot_number/plate/occurred_at/photo），自动归并 |
| GET | /api/events | 登录 | 列表（按角色过滤与排序） |
| GET | /api/events/{id} | 登录 | 详情（权限控制） |
| GET | /api/reports/{id}/photo | 登录 | 现场照片（权限控制） |
| POST | /api/events/{id}/verify | 值班员 | 核实，须人工确认车牌 |
| POST | /api/events/{id}/reject | 值班员 | 驳回 |
| POST | /api/events/{id}/notify | 值班员 | 模拟短信通知（可再次通知） |
| POST | /api/events/{id}/rechecks | 巡查员 | 复查登记 left / still_occupied |
| POST | /api/events/{id}/close | 值班员 | 结案（须复查确认离开） |

环境变量：`PORT`（默认 3000）、`DATABASE_PATH`（默认 data/parking.db）、`UPLOAD_DIR`（默认 uploads）、`STATIC_DIR`（默认 frontend/dist）。
